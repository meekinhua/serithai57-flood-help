# 🌊 ช่วยกันน้ำท่วม เสรีไทย 57

ระบบช่วยเหลือกันในชุมชนช่วงน้ำท่วม สำหรับ **บ้านสหกรณ์เคหะสถาน 4 ซ.เสรีไทย 57 แขวงคลองกุ่ม เขตบึงกุ่ม**
แผนที่และขอบเขตหมู่บ้านใช้ข้อมูลจาก OpenStreetMap (way 1478507497)

ใช้งานได้ทันทีโดยไม่ต้องสมัครสมาชิก:
- 🆘 **ขอความช่วยเหลือ**: ติดอยู่ ผู้ป่วย ผู้สูงอายุ อาหาร ยา ไฟฟ้า สัตว์เลี้ยง (ติ๊ก "ด่วนมาก" ได้)
- 🤝 **ฉันช่วยได้**: เรือ รถยกสูง อาหาร ที่พัก ที่จอดรถบนที่สูง แรงงาน จุดชาร์จไฟ
- 💰 **ยินดีจ่าย / รับจ้าง**: ทั้งคำขอและข้อเสนอเลือกได้ว่าฟรีหรือมีค่าตอบแทน พร้อมระบุราคา ระบบไม่รับเงิน ให้ตกลงและจ่ายกันเอง
- 💧 **แจ้งระดับน้ำ**: เลือกระดับเทียบกับร่างกาย แล้วแสดงเป็นจุดสีบนแผนที่
- 📍 **แจ้งข้อมูล**: ถนนผ่านได้หรือไม่ได้ จุดอันตราย ศูนย์พักพิง จุดแจกของ
- ทุกคนกด "ฉันจะไปช่วย" หรือ "ช่วยเสร็จแล้ว" ได้ ระบบเก็บประวัติว่าใครทำอะไรเมื่อไร
- ปุ่ม **คัดลอกสรุปไป LINE** และหน้ารวมเบอร์ฉุกเฉิน
- หน้าจอรีเฟรชข้อมูลเองทุก 20 วินาที

## Stack (Emergent spec)
- `frontend/`: React (CRA) + Tailwind + Leaflet/OSM tiles, yarn, port 3000
- `backend/`: FastAPI + motor (MongoDB), port 8001, ทุก route อยู่ใต้ `/api`
- ไม่มีระบบล็อกอิน ผู้โพสต์ได้ edit key ที่เก็บไว้ในเบราว์เซอร์ของตัวเองสำหรับลบโพสต์ และจำกัดความถี่การโพสต์ต่อ IP

## API
| Method | Path | |
|---|---|---|
| GET | /api/health | health check |
| GET | /api/posts?kind=&include_done= | รายการ |
| POST | /api/posts | สร้างรายการ (response มี `edit_key`) |
| POST | /api/posts/{id}/status | เปลี่ยนสถานะ open / helping / done |
| DELETE | /api/posts/{id} | ลบ (ต้องส่ง header `X-Edit-Key`) |
| GET/POST | /api/water | รายงานระดับน้ำ |

เอกสาร API แบบเต็มดูได้ที่ `/api/docs`
