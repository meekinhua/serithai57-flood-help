# 🌊 ช่วยกันน้ำท่วม เสรีไทย 57

ระบบช่วยเหลือกันในชุมชนช่วงน้ำท่วม สำหรับ **บ้านสหกรณ์เคหะสถาน 4 ซ.เสรีไทย 57 แขวงคลองกุ่ม เขตบึงกุ่ม**
แผนที่และขอบเขตหมู่บ้านใช้ข้อมูลจาก OpenStreetMap (way 1478507497)

ใช้งานได้ทันทีโดยไม่ต้องสมัครสมาชิก:
- 🆘 **ขอความช่วยเหลือ**: ติดอยู่ ผู้ป่วย ผู้สูงอายุ อาหาร ยา ไฟฟ้า สัตว์เลี้ยง (ติ๊ก "ด่วนมาก" ได้)
- 🤝 **ฉันช่วยได้**: เรือ รถยกสูง อาหาร ที่พัก ที่จอดรถบนที่สูง แรงงาน จุดชาร์จไฟ
- 📇 **บอร์ดติดต่อ: ช่าง · รถ · รับจ้าง** (อยู่ล่างสุดของหน้าแรก ให้แผนที่และคำขอความช่วยเหลือเด่นกว่า): สมุดรายชื่อช่างไฟ ช่างประปา รถยกสูง เช่ารถ เรือรับจ้าง คนขนของ/หิ้วของ ล้างบ้าน ฯลฯ มีปุ่มโทร/LINE สถานะว่าง/ไม่ว่าง ราคา และแท็บ "คนกำลังหาคนจ้าง" · ลงชื่อรับงานได้โดยไม่ต้องสมัคร · แจ้ง "โทรไม่ติด" ได้ · ผู้ดูแลกดยืนยัน/ปักหมุด/ลบได้
- 💰 **ยินดีจ่าย / รับจ้าง**: ทั้งคำขอและข้อเสนอเลือกได้ว่าฟรีหรือมีค่าตอบแทน พร้อมระบุราคา ระบบไม่รับเงิน ให้ตกลงและจ่ายกันเอง
- 💧 **แจ้งระดับน้ำ**: เลือกระดับเทียบกับร่างกาย แล้วแสดงเป็นจุดสีบนแผนที่
- 🌊 **ระบายสีระดับน้ำ**: เกลี่ยสีบนแผนที่จากรายงานทั้งหมด (IDW: ใกล้/ใหม่กว่ามีน้ำหนักมากกว่า) พื้นที่ไกลจากรายงานเกิน 300 ม. ไม่ระบาย แตะแผนที่เพื่อดูระดับโดยประมาณ ณ จุดนั้น
- 📍 **แจ้งข้อมูล**: ถนนผ่านได้หรือไม่ได้ จุดอันตราย ศูนย์พักพิง จุดแจกของ
- ทุกคนกด "ฉันจะไปช่วย" หรือ "ช่วยเสร็จแล้ว" ได้ ระบบเก็บประวัติว่าใครทำอะไรเมื่อไร
- ปุ่ม **คัดลอกสรุปไป LINE** และหน้ารวมเบอร์ฉุกเฉิน
- 📷 **แนบรูป / คลิป**: โพสต์ละไม่เกิน 4 ไฟล์ รายงานระดับน้ำแนบรูปได้ 1 รูป ระบบย่อให้อัตโนมัติ (รูป ≤1600px, คลิป 480p เก็บ 60 วินาทีแรก เป็น MP4 เปิดได้ทุกเครื่อง) และลบพิกัด GPS ออกจากรูป
- 📢 **ประกาศจากผู้ดูแล**: แถบใหญ่บนสุดของหน้า มี 3 ระดับ (🚨 อันตราย / ⚠️ เตือน / 📢 ทั่วไป) ตั้งเวลาหมดอายุได้ และติดไปในสรุป LINE ด้วย

- 🎬 **คู่มือแบบแอนิเมชัน**: เปิดครั้งแรกจะมีคู่มือ 5 หน้า (เลื่อนเองแบบ story ปัดซ้ายขวาได้) เปิดดูใหม่ได้ที่ปุ่ม ❓ ในแอปมีแอนิเมชันเบา ๆ ช่วยให้เข้าใจ: หน้าต่างเลื่อนขึ้น รายการใหม่กะพริบ หมุดใหม่ตกลงบนแผนที่ ตัวเลขนับขึ้น และรูปคนยืนในน้ำตามระดับที่เลือก (ปิดอัตโนมัติถ้าเครื่องตั้ง "ลดการเคลื่อนไหว")

- 🌦️ **สภาพอากาศ + เตือนอัตโนมัติ**: การ์ดสภาพอากาศตอนนี้ + กราฟฝนรายชั่วโมง 12 ชม. (ข้อมูล Open-Meteo, เซิร์ฟเวอร์ cache 10 นาที) และแถบเตือนอัตโนมัติเมื่อมีพายุฝนฟ้าคะนอง ฝนหนัก (≥10 มม./ชม. หรือสะสม 6 ชม. ≥20 มม.) ฝนต่อเนื่อง หรือลมกระโชก ≥40 กม./ชม. — ปุ่ม "แผนที่ลม/ฝน/เมฆ" เปิดแผนที่เคลื่อนไหวของ Windy.com (embed ฟรี โหลดเมื่อกดเท่านั้นเพราะใช้เน็ตมาก)

## กันการลงผิด (จากการวิเคราะห์การใช้งานจริงบน serithai57.com)
- **ขอความช่วยเหลือที่ลงผิดประเภท**: ถ้าข้อความใน “แจ้งข้อมูล/ฉันช่วยได้” มีคำอย่าง ผู้สูงอายุ ติดเตียง เด็ก ไม่มีไฟ ต้องการ ฯลฯ จะถามก่อนส่งว่าเป็นคำขอหรือไม่ และเปลี่ยนให้ในคลิกเดียว (เดาหมวด + ด่วน + จำนวนคนจากข้อความ) · ผู้ดูแลแก้ประเภทโพสต์ที่ลงผิดได้ในหน้ารายละเอียด
- **ปุ่ม “ด่วนมาก”** อยู่บนสุดของฟอร์ม และเปิดให้อัตโนมัติเมื่อเลือกหมวด ติดอยู่/อพยพ, เจ็บป่วย, ผู้สูงอายุ/ติดเตียง/เด็กเล็ก
- **หมุดไม่ได้เลื่อน**: เตือนก่อนส่งถ้ายังไม่ได้ลากแผนที่หรือกด GPS · ข่าวทั่วไปเลือก “ทั้งหมู่บ้าน / ไม่ระบุจุด” ได้ (ไม่ปักหมุด)
- **โพสต์ซ้ำ**: ถ้าบ้าน/จุดเดิมมีคำขอค้างอยู่ จะชวนไปอัปเดตโพสต์เดิม (“💬 ส่งข้อความอัปเดต” โดยไม่เปลี่ยนสถานะ) · แจ้งระดับน้ำจุดเดิมซ้ำใน 10 นาทีจะถามก่อน
- **ระดับน้ำ**: ใส่ความสูงเป็นเซนติเมตรได้ (เลือกระดับให้เอง เช่น 65 ซม. = ต้นขา) + แนวโน้ม ⬆️/➡️/⬇️ + วัดบนถนน/ในบ้าน · หมายเหตุที่ดูเหมือนขอความช่วยเหลือ จะเปิดฟอร์มขอความช่วยเหลือให้ต่อ
- **ถนน**: เพิ่มหมวด “⚠️ ผ่านได้บางส่วน / มีสิ่งกีดขวาง”
- **รายการ**: คำขอขึ้นก่อนเสมอ (ด่วน → ค้าง → ล่าสุด) · ป้าย “⏳ รอมา X ชม.” เมื่อไม่มีใครรับเรื่อง 3 ชม. · ข้อมูลเก่ากว่า 12 ชม. พับไว้
- **คนที่กด “ฉันจะไปช่วย”** จะถูกถามหลัง 2 ชม. ว่าเสร็จหรือยัง
- **ประกาศ**: ค่าเริ่มต้นหมดอายุ 24 ชม. · เกิน 6 ชม. ขึ้น “อาจไม่เป็นปัจจุบัน” และหยุดกะพริบ · ข้อความยาวพับเหลือ 3 บรรทัด
- **ปุ่ม 🆘 ลอย** มุมล่างขวาบนมือถือเมื่อปุ่มหลักเลื่อนพ้นจอ
- **ความเป็นส่วนตัว**: เบอร์โทรไม่อยู่ในรายการรวม ต้องกด “แสดงเบอร์โทร” ทีละโพสต์ (`GET /api/posts/{id}/contact`, จำกัดความถี่) และไม่อยู่ในสรุปที่ส่งเข้า LINE

## เครื่องมือเจ้าหน้าที่ (`/staff`)
- **เข้าใช้**: ผู้ดูแลสร้าง “ลิงก์เชิญ” ที่ `/admin` → แท็บ 👷 เจ้าหน้าที่ · เจ้าหน้าที่เปิดลิงก์ ใส่ชื่อ ใช้ได้ทันที (จัดการผู้ดูแล/ประกาศไม่ได้)
- **📋 งาน**: คำขอความช่วยเหลือทั้งหมด (ไม่รวมงานรับจ้าง) จัดกลุ่มตามซอย · “รับงานนี้” / “รับทั้งซอย” — **คนเดียวรับได้ต่องาน** (คนที่สองจะเห็นว่าใครรับไปแล้ว) · ปล่อยงาน · เสร็จพร้อมบันทึก · โทร/นำทาง · คัดลอก “งานของฉัน”
- **🗺️ แผนที่**: เส้นซอยจาก OSM + งานทุกหลัง (แดง=ด่วนว่าง ส้ม=ว่าง น้ำเงิน=ของฉัน เทา=คนอื่นรับ วงประ=ตำแหน่งโดยประมาณ)
- **📥 นำเข้า LINE (ส่วนกลางทำให้ เจ้าหน้าที่ไม่ต้องทำ)**: แท็บนี้เห็นเฉพาะผู้ดูแลและบัญชีนำเข้า (`importer`) · API `/api/staff/import/*` ปฏิเสธเจ้าหน้าที่ทั่วไป (403) · เลือกไฟล์ที่ “บันทึกแชท” จาก LINE PC → ตัดรายการที่ก๊อปซ้ำ, ข้ามโพสต์ขายของ/พรีออเดอร์, ไม่นับเลขที่ในชื่อผู้โพสต์ → เลือกแล้วสร้างงาน (บ้านที่มีงานค้างอยู่แล้วจะรวมเป็นบันทึกในงานเดิม ไม่สร้างซ้ำ)
- **🏠 ที่อยู่ (สมุดที่อยู่ของหมู่บ้าน)**: แตะอาคาร (1,537 หลังจาก OSM) แล้วบันทึกว่า “คือบ้าน 4/xxx” · มีปุ่มเปิด Google Maps ให้ดูเอง (ระบบไม่ดึง/เก็บข้อมูล Google อัตโนมัติ ตามเงื่อนไขของ Google) · ชาวบ้านที่ปักหมุดตอนขอความช่วยเหลือก็เติมสมุดนี้ให้อัตโนมัติ
- **ความแม่นของตำแหน่ง**: 📍 บ้าน (เจ้าหน้าที่/ชาวบ้านปักเอง) → ≈ ต้นซอย (แชตบอกซอย) → ≈ ซอยโดยประมาณ (เดาจากเลขที่บ้านใกล้เคียง) → ❓ ไม่ทราบ
- **🔎 ค้นเลขที่**: สำหรับประกาศตามเลขที่บ้าน เช่น “4/100–4/250” → บอกว่าอยู่ซอยไหน และบ้านไหนมีคำขอค้าง
- ข้อมูลซอยและอาคาร: `backend/data/sois.json`, `backend/data/buildings.json` (© OpenStreetMap contributors, ODbL)
- สคริปต์ offline: `tools/line_digest.py` (อยู่นอก repo) ทำสรุปจากไฟล์แชตได้โดยไม่ต้องเปิดแอป
- **นำเข้าซ้ำได้ปลอดภัย**: บ้านที่มีงานค้างอยู่แล้ว → เพิ่มบันทึก (ข้อความเดิมไม่บันทึกซ้ำ) · บ้านที่เพิ่งช่วยเสร็จใน 24 ชม. → ข้าม (รายการก๊อปต่อในแชตยังมีบ้านเก่าอยู่) เว้นแต่ติ๊กเลือกเอง
- **เคลียร์งานจากแชต**: ข้อความแบบ “4/852 ได้รับข้าวแล้ว”, “ได้รับความช่วยเหลือแล้ว”, “ส่งข้าวแล้ว”, “ไม่ต้องแล้ว”, “✅” → ตอนนำเข้า ปิดงานที่ค้างของบ้านนั้น (บันทึก “แจ้งใน LINE ว่าได้รับแล้ว: …” ในประวัติ) ไม่สร้างงานใหม่ · “ยังไม่ได้รับ / ยังรอ” ไม่ปิด (และเปิดสถานะกลับ) · ข้อความสั้นที่พูดถึงบ้านเดียวนับทั้งข้อความ · ลิสต์ที่ก๊อปต่อทีหลังไม่ทำให้บ้านที่ได้รับแล้วกลับมาเป็นงาน · ตัวอย่างก่อนส่งแสดงรายชื่อบ้านที่จะปิดพร้อมข้อความ · `tools/line_watch.py --rescan-received` อ่านทั้งแชตใหม่เพื่อปิดอย่างเดียว
- สคริปต์ส่งจากเครื่อง: `tools/push_line.py` (อยู่นอก repo) อ่านไฟล์ `[LINE]*.txt` ล่าสุดใน Downloads → แสดงสรุป → `--commit` ส่งเข้าเว็บในนามบัญชีนำเข้า “Claude · นำเข้า LINE” (สร้างจากลิงก์เชิญแบบ `importer: true`)

## ติดตามรถ/เรือแบบเรียลไทม์
- **โซน A–I + จุดลงของ** (`/zones`, `GET /api/zones`, คำนวณด้วย `backend/data/make_zones.py` จาก sois.json + buildings.json): แบ่งหมู่บ้าน ~170 หลังต่อโซน เป็นช่วงของถนนหลัก (เสรีไทย 57) พร้อมซอยสองฝั่ง · จุดลงของ 🚚 ต่อโซน = ปากซอยบนถนนหลักกลางโซน (รถใหญ่เข้าซอยเล็กไม่ได้) · หน้า /zones: แผนที่สีตามโซน, ถนนหลักเส้นเหลือง, การ์ดต่อโซน (ซอย จำนวนบ้าน คำขอค้าง ปุ่มนำทาง), ปุ่มพิมพ์ · `/zones?poster=1` = แบบภาพนิ่ง ไม่มีปุ่ม · เจ้าหน้าที่: กรองงานตามโซน (จำโซนของทีมไว้ในเครื่อง), แผนที่เจ้าหน้าที่แสดงโซนและจุดลงของ · งานทุกชิ้นมี `zone` · แก้จำนวนบ้านต่อโซน: `TARGET_PER_ZONE` แล้วรันสคริปต์ใหม่
- **ดูระดับน้ำ**: สวิตช์ใหญ่บนแผนที่ [🆘 คำขอช่วย | 💧 ระดับน้ำ] (เปิดมาที่คำขอช่วยเสมอ) · โหมดระดับน้ำซ่อนหมุดคำขอ แสดงสีระดับน้ำ + จุดรายงานจริง + คำอธิบายสี + “👆 แตะที่ไหนก็ได้เพื่อดูระดับน้ำ” + ปุ่ม “📍 น้ำตรงที่ฉันอยู่” (GPS) · แตะช่อง “ระดับน้ำสูงสุด” หรือ “ดูบนแผนที่” ของรายงานน้ำ → เปิดโหมดระดับน้ำให้เอง · โหมดคำขอช่วยยังมีปุ่ม 🌊 สีน้ำ มุมซ้ายล่าง
- **แผนที่ไม่รก** (MapView): ค่าเริ่มต้นแสดงเฉพาะเรื่องหลัก = คำขอช่วย + เจ้าหน้าที่ + สีระดับน้ำ · คำขอด่วนเป็นหมุดแยกเสมอ คำขออื่นรวมเป็นกลุ่มตัวเลข (leaflet.markercluster, แยกหมดที่ซูม 18; ป้ายแดง = ยังไม่มีคนช่วย) · ช่วยได้ / ข้อมูล ซ่อนไว้ เปิดด้วยปุ่มมุมซ้ายล่างของแผนที่ (จุดวัดน้ำอยู่ในโหมด 💧 ระดับน้ำ) (จำค่าไว้ในเครื่อง) · ถ้าเลือกตัวกรองเหนือแผนที่ ตัวกรองนั้นชนะ
- **เจ้าหน้าที่เปิดมาเจอแผนที่ก่อน**: แตะจุดงาน → การ์ดใต้แผนที่ มีปุ่ม 🙋 รับงาน · ✅ เคลียร์/เสร็จแล้ว (เคลียร์ได้แม้ยังไม่ได้รับ) · ✏️ แก้ไข (ประเภท จำนวน +/− ด่วน รายละเอียด; `PATCH /api/staff/tasks/{id}` บันทึกในประวัติ, คนอื่นรับอยู่แก้ไม่ได้)
- **ไอคอนเจ้าหน้าที่บนแผนที่เด่นกว่าหมุดทั่วไป** (`components/staffMarkers.js`): วงกลมใหญ่ 54px สีทีม (🔵 ออกงาน · 🟢 ออนไลน์ · ⚪ ไม่มีสัญญาณเกิน 3 นาที) ขอบขาว วงแหวนกะพริบ ป้าย “ออกงาน/ทีมช่วยเหลือ” + ชื่อใต้หมุด · ไอคอนตามยานพาหนะ 🚤 เรือ · 🚛 รถใหญ่/รถทหาร · 🛻 กระบะ/รถยกสูง · 🚗 รถเก๋ง · 🏍️ มอเตอร์ไซค์ · 👷 เดินเท้า — ตอนออนไลน์เลือกได้ในแถบบนของ `/staff` · แผนที่ของเจ้าหน้าที่ก็เห็นเพื่อนร่วมทีมด้วย
- **ทุกคนที่เปิด `/staff` อยู่** ขึ้นบนแผนที่หน้าแรกเป็น 👷 (ชื่อ · หน่วยที่มา) · แตะแล้วเห็น “กำลังจะทำอะไร” ที่เขียนไว้ + งานที่รับไว้ (กี่หลัง ซอยไหน) · GPS ทำงานตลอดที่เปิดหน้า ไม่ว่าอยู่แท็บไหน · ปุ่ม ⏸ หยุดแชร์ · ตำแหน่งหยาบ/อยู่นอกพื้นที่ไม่ถูกปฏิเสธแล้ว แต่ขึ้นคำเตือน (นอกรัศมี 15 กม. เห็นแค่ชื่อ ไม่ปักหมุด)
- **ลิงก์ที่ส่งทาง LINE / Messenger** ใช้ในเบราว์เซอร์ของแอปแชตได้เลย ไม่บังคับย้าย: ระหว่างแชร์ตำแหน่ง ระบบกันจอดับด้วย Wake Lock และถ้าแอปไม่ยอม ใช้วิดีโอเงียบวนสั้นๆ (จาก nosleep.js) แทน (ต้องแตะจอ 1 ครั้ง) · **แนะนำให้ย้ายไป Safari/Chrome เฉพาะเมื่อ** กันจอดับไม่ได้จริงหลังแตะจอ หรือแอปไม่ให้ใช้ GPS → แถบเหลือง “ย้ายไป Safari/Chrome (ไม่ต้องใส่ชื่อใหม่)” (โทเคนใช้ครั้งเดียว 10 นาที: `POST /api/staff/handoff` → `/staff?login=…` → `POST /api/auth/staff-handoff`) + แอนิเมชันสอน (มือถือจำลอง แตะ ⋮ → เปิดในเบราว์เซอร์ · เลือก LINE/Messenger, iPhone/Android · แตะเลขขั้นเพื่อหยุดดู) · แท็บ “ชวนทีม” มีคู่มือเดียวกัน · ดูหน้าจอแบบในแอปจากคอม: `/staff?inapp=line-ios` (หรือ `messenger-android` ฯลฯ)
- **GPS กับจอดับ**: เว็บไม่ได้รับ GPS ตอนจอดับ/สลับแอป (ข้อจำกัดของ iOS/Android) → ระหว่างแชร์ ระบบสั่งเปิดจอค้าง (Wake Lock, ขอใหม่เมื่อแตะจอ/กลับมาที่หน้า) และส่งตำแหน่งทันทีเมื่อกลับมา · ถ้าเบราว์เซอร์ไม่รองรับ ขึ้นวิธีตั้ง “ล็อกอัตโนมัติ = ไม่เลย”
- **แจกสิทธิ์ง่าย**: แท็บ **👥 ชวนทีม** มี QR ให้สแกน + ปุ่มส่งทาง LINE + คัดลอกข้อความ · หน้าเข้าร่วมถามแค่ชื่อ และ “มาจากหน่วยไหน” (ไม่บังคับ)
- เจ้าหน้าที่: `/staff` → แท็บ **🚤 ออกงาน** เลือกยานพาหนะ (เรือ/รถยกสูง/รถ/เดินเท้า) + ภารกิจ (แจกข้าว/น้ำ/รับคน/ผู้ป่วย/ขนของ/สำรวจ) → มือถือส่ง GPS อัตโนมัติ (ทุก ~25 วินาที หรือเมื่อเคลื่อนที่ 20 ม.) พร้อมกันจอดับ (Wake Lock) · กดสถานะ: กำลังไป → กำลังแจก → ของหมด → กลับฐาน · จบงาน = หยุดแชร์
- ชาวบ้าน: แถบ **“🚚 กำลังให้บริการตอนนี้”** ใต้ปุ่มหลัก (ซอยที่อยู่ สถานะ ข้อความ) + ไอคอนเคลื่อนที่พร้อมเส้นทางบนแผนที่ อัปเดตทุก 10 วินาที · ไม่แสดงชื่อ/บัญชีเจ้าหน้าที่ แสดงเฉพาะชื่อที่ตั้งเอง · ไม่มีสัญญาณเกิน 15 นาทีจะซ่อนอัตโนมัติ
- ข้อจำกัด: ต้องเปิดหน้าไว้ ถ้าจอดับ/สลับแอป เบราว์เซอร์จะหยุดส่งตำแหน่ง

## ผู้ดูแล (admin)
- **ลิงก์ลับ (เข้าเร็ว ไม่ต้องล็อกอิน):** `<เว็บ>/admin#key=<ADMIN_URL_KEY>` ค่าอยู่ใน `backend/.env` ใครมีลิงก์นี้ก็เป็นผู้ดูแลได้ ถ้าลิงก์หลุด ให้เปลี่ยน `ADMIN_URL_KEY` แล้วรีสตาร์ต backend
- **ล็อกอินด้วยอีเมล/รหัสผ่าน:** ที่ `/admin` บัญชีแรกสร้างจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` (ดู `memory/test_credentials.md`) ควรเปลี่ยนรหัสผ่านที่แท็บ "บัญชี"
- ผู้ดูแลทำได้: สร้าง / ปิด / ลบประกาศ, ปักหมุดหรือลบรายการใดก็ได้, ลบรายงานระดับน้ำ, เพิ่มหรือลบผู้ดูแลคนอื่น และดูประวัติการจัดการทั้งหมด
- ระดับน้ำมี 7 ระดับ: ไม่ท่วม · ตาตุ่ม · ครึ่งแข้ง · เข่า · **ต้นขา (60–70 ซม.)** · เอว · อกขึ้นไป (ข้อมูลเก่าถูกแปลงให้อัตโนมัติ)
- หน้าจอรีเฟรชข้อมูลเองทุก 20 วินาที และแสดง **"🟢 N คนกำลังดู"** (นับเครื่องที่เปิดหน้าอยู่ใน 60 วินาทีล่าสุด ไม่เก็บข้อมูลตัวตน)

## Stack (Emergent spec)

## สภาพอากาศบนโฮสต์ที่ใช้ IP ร่วมกัน (เช่น Emergent pod)
Open-Meteo ฟรีจำกัดจำนวนครั้ง**ต่อวันต่อ IP** บน pod ที่ออกเน็ตผ่าน IP เดียวกับแอปอื่น โควต้าอาจหมดโดยที่แอปเราแทบไม่ได้เรียก (ได้ `429 Daily API request limit exceeded`)
- backend จะข้าม Open-Meteo ไปจนถึง 00:05 UTC ของวันถัดไปแล้วใช้ **MET Norway** แทนอัตโนมัติ (ฟรี ไม่มีโควต้ารายวันต่อ IP)
- ค่าล่าสุดที่ดึงได้เก็บใน MongoDB (`weather_cache`) รีสตาร์ตแล้วยังมีข้อมูลแสดง (ข้อมูลเก่ากว่า 3 ชม. จะแสดงแต่ไม่ออกคำเตือน)
- ถ้าไม่มีแหล่งไหนตอบเลย หน้าเว็บจะขึ้น "ข้อมูลอากาศไม่พร้อมชั่วคราว" + ปุ่มแผนที่ Windy (โหลดจากมือถือโดยตรง) แทนการหายไป
- เลือก/เรียงแหล่งข้อมูลได้ด้วย `WEATHER_PROVIDERS` ใน `backend/.env` เช่น `WEATHER_PROVIDERS=met-norway` เพื่อไม่ใช้ Open-Meteo เลย
- ดูสถานะได้ที่ `GET /api/weather/status`
