# 🌊 ช่วยกันน้ำท่วม เสรีไทย 57

ระบบช่วยเหลือกันในชุมชนช่วงน้ำท่วม สำหรับ **บ้านสหกรณ์เคหะสถาน 4 ซ.เสรีไทย 57 แขวงคลองกุ่ม เขตบึงกุ่ม**
แผนที่และขอบเขตหมู่บ้านใช้ข้อมูลจาก OpenStreetMap (way 1478507497)

ใช้งานได้ทันทีโดยไม่ต้องสมัครสมาชิก:
- 🆘 **ขอความช่วยเหลือ**: ติดอยู่ ผู้ป่วย ผู้สูงอายุ อาหาร ยา ไฟฟ้า สัตว์เลี้ยง (ติ๊ก "ด่วนมาก" ได้)
- 🤝 **ฉันช่วยได้**: เรือ รถยกสูง อาหาร ที่พัก ที่จอดรถบนที่สูง แรงงาน จุดชาร์จไฟ
- 💰 **ยินดีจ่าย / รับจ้าง**: ทั้งคำขอและข้อเสนอเลือกได้ว่าฟรีหรือมีค่าตอบแทน พร้อมระบุราคา ระบบไม่รับเงิน ให้ตกลงและจ่ายกันเอง
- 💧 **แจ้งระดับน้ำ**: เลือกระดับเทียบกับร่างกาย แล้วแสดงเป็นจุดสีบนแผนที่
- 🌊 **ระบายสีระดับน้ำ**: เกลี่ยสีบนแผนที่จากรายงานทั้งหมด (IDW: ใกล้/ใหม่กว่ามีน้ำหนักมากกว่า) พื้นที่ไกลจากรายงานเกิน 300 ม. ไม่ระบาย แตะแผนที่เพื่อดูระดับโดยประมาณ ณ จุดนั้น
- 📍 **แจ้งข้อมูล**: ถนนผ่านได้หรือไม่ได้ จุดอันตราย ศูนย์พักพิง จุดแจกของ
- ทุกคนกด "ฉันจะไปช่วย" หรือ "ช่วยเสร็จแล้ว" ได้ ระบบเก็บประวัติว่าใครทำอะไรเมื่อไร
- ปุ่ม **คัดลอกสรุปไป LINE** และหน้ารวมเบอร์ฉุกเฉิน
- 📷 **แนบรูป / คลิป**: โพสต์ละไม่เกิน 4 ไฟล์ รายงานระดับน้ำแนบรูปได้ 1 รูป ระบบย่อให้อัตโนมัติ (รูป ≤1600px, คลิป 480p เก็บ 60 วินาทีแรก เป็น MP4 เปิดได้ทุกเครื่อง) และลบพิกัด GPS ออกจากรูป
- 📢 **ประกาศจากผู้ดูแล**: แถบใหญ่บนสุดของหน้า มี 3 ระดับ (🚨 อันตราย / ⚠️ เตือน / 📢 ทั่วไป) ตั้งเวลาหมดอายุได้ และติดไปในสรุป LINE ด้วย

## ผู้ดูแล (admin)
- **ลิงก์ลับ (เข้าเร็ว ไม่ต้องล็อกอิน):** `<เว็บ>/admin#key=<ADMIN_URL_KEY>` ค่าอยู่ใน `backend/.env` ใครมีลิงก์นี้ก็เป็นผู้ดูแลได้ ถ้าลิงก์หลุด ให้เปลี่ยน `ADMIN_URL_KEY` แล้วรีสตาร์ต backend
- **ล็อกอินด้วยอีเมล/รหัสผ่าน:** ที่ `/admin` บัญชีแรกสร้างจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` (ดู `memory/test_credentials.md`) ควรเปลี่ยนรหัสผ่านที่แท็บ "บัญชี"
- ผู้ดูแลทำได้: สร้าง / ปิด / ลบประกาศ, ปักหมุดหรือลบรายการใดก็ได้, ลบรายงานระดับน้ำ, เพิ่มหรือลบผู้ดูแลคนอื่น และดูประวัติการจัดการทั้งหมด
- ระดับน้ำมี 7 ระดับ: ไม่ท่วม · ตาตุ่ม · ครึ่งแข้ง · เข่า · **ต้นขา (60–70 ซม.)** · เอว · อกขึ้นไป (ข้อมูลเก่าถูกแปลงให้อัตโนมัติ)
- หน้าจอรีเฟรชข้อมูลเองทุก 20 วินาที และแสดง **"🟢 N คนกำลังดู"** (นับเครื่องที่เปิดหน้าอยู่ใน 60 วินาทีล่าสุด ไม่เก็บข้อมูลตัวตน)

## Stack (Emergent spec)
- `frontend/`: React (CRA) + Tailwind + Leaflet/OSM tiles, yarn, port 3000
- `backend/`: FastAPI + motor (MongoDB), port 8001, ทุก route อยู่ใต้ `/api`
- ไม่มีระบบล็อกอิน ผู้โพสต์ได้ edit key ที่เก็บไว้ในเบราว์เซอร์ของตัวเองสำหรับลบโพสต์ และจำกัดความถี่การโพสต์ต่อ IP

## API
| Method | Path | |
|---|---|---|
| GET | /api/health | health check |
| GET | /api/posts?kind=&include_done= | รายการ |
| POST | /api/posts | สร้างรายการ (response มี `edit_key`) |
| POST | /api/posts/{id}/status | เปลี่ยนสถานะ open / helping / done |
| DELETE | /api/posts/{id} | ลบ (ต้องส่ง header `X-Edit-Key`) |
| GET/POST | /api/water | รายงานระดับน้ำ |
| GET | /api/announcements | ประกาศที่กำลังแสดง |
| GET, POST | /api/presence, /api/presence/leave | จำนวนคนที่กำลังดู (ping ทุก 20 วินาที) |
| POST, PUT, GET | /api/media, /api/media/{id}/chunk/{i}, /api/media/{id}/complete, /api/media/{id}/file, /api/media/{id}/thumb | อัปโหลดรูป/คลิปแบบแบ่งชิ้น (1 MB) และเปิดดูไฟล์ (เก็บใน MongoDB GridFS) |
| POST | /api/auth/login, /api/auth/key, /api/auth/logout | เข้า/ออกโหมดผู้ดูแล (session cookie) |
| * | /api/admin/... | ประกาศ, ปักหมุด/ลบรายการ, ลบระดับน้ำ, ผู้ดูแล, ประวัติ (ต้องเป็นผู้ดูแล) |

เอกสาร API แบบเต็มดูได้ที่ `/api/docs`
