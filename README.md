# 🌊 ช่วยกันน้ำท่วม เสรีไทย 57

ระบบช่วยเหลือกันในชุมชนช่วงน้ำท่วม สำหรับ **บ้านสหกรณ์เคหะสถาน 4 ซ.เสรีไทย 57 แขวงคลองกุ่ม เขตบึงกุ่ม**
แผนที่และขอบเขตหมู่บ้านใช้ข้อมูลจาก OpenStreetMap (way 1478507497)

ใช้งานได้ทันทีโดยไม่ต้องสมัครสมาชิก:
- 🆘 **ขอความช่วยเหลือ**: ติดอยู่ ผู้ป่วย ผู้สูงอายุ อาหาร ยา ไฟฟ้า สัตว์เลี้ยง (ติ๊ก "ด่วนมาก" ได้)
- 🤝 **ฉันช่วยได้**: เรือ รถยกสูง อาหาร ที่พัก ที่จอดรถบนที่สูง แรงงาน จุดชาร์จไฟ
- 📇 **บอร์ดติดต่อ: ช่าง · รถ · รับจ้าง** (อยู่ใต้ปุ่มหลัก เห็นทันที): สมุดรายชื่อช่างไฟ ช่างประปา รถยกสูง เช่ารถ เรือรับจ้าง คนขนของ/หิ้วของ ล้างบ้าน ฯลฯ มีปุ่มโทร/LINE สถานะว่าง/ไม่ว่าง ราคา และแท็บ "คนกำลังหาคนจ้าง" · ลงชื่อรับงานได้โดยไม่ต้องสมัคร · แจ้ง "โทรไม่ติด" ได้ · ผู้ดูแลกดยืนยัน/ปักหมุด/ลบได้
- 💰 **ยินดีจ่าย / รับจ้าง**: ทั้งคำขอและข้อเสนอเลือกได้ว่าฟรีหรือมีค่าตอบแทน พร้อมระบุราคา ระบบไม่รับเงิน ให้ตกลงและจ่ายกันเอง
- 💧 **แจ้งระดับน้ำ**: เลือกระดับเทียบกับร่างกาย แล้วแสดงเป็นจุดสีบนแผนที่
- 🌊 **ระบายสีระดับน้ำ**: เกลี่ยสีบนแผนที่จากรายงานทั้งหมด (IDW: ใกล้/ใหม่กว่ามีน้ำหนักมากกว่า) พื้นที่ไกลจากรายงานเกิน 300 ม. ไม่ระบาย แตะแผนที่เพื่อดูระดับโดยประมาณ ณ จุดนั้น
- 📍 **แจ้งข้อมูล**: ถนนผ่านได้หรือไม่ได้ จุดอันตราย ศูนย์พักพิง จุดแจกของ
- ทุกคนกด "ฉันจะไปช่วย" หรือ "ช่วยเสร็จแล้ว" ได้ ระบบเก็บประวัติว่าใครทำอะไรเมื่อไร
- ปุ่ม **คัดลอกสรุปไป LINE** และหน้ารวมเบอร์ฉุกเฉิน
- 📷 **แนบรูป / คลิป**: โพสต์ละไม่เกิน 4 ไฟล์ รายงานระดับน้ำแนบรูปได้ 1 รูป ระบบย่อให้อัตโนมัติ (รูป ≤1600px, คลิป 480p เก็บ 60 วินาทีแรก เป็น MP4 เปิดได้ทุกเครื่อง) และลบพิกัด GPS ออกจากรูป
- 📢 **ประกาศจากผู้ดูแล**: แถบใหญ่บนสุดของหน้า มี 3 ระดับ (🚨 อันตราย / ⚠️ เตือน / 📢 ทั่วไป) ตั้งเวลาหมดอายุได้ และติดไปในสรุป LINE ด้วย

- 🎬 **คู่มือแบบแอนิเมชัน**: เปิดครั้งแรกจะมีคู่มือ 5 หน้า (เลื่อนเองแบบ story ปัดซ้ายขวาได้) เปิดดูใหม่ได้ที่ปุ่ม ❓ ในแอปมีแอนิเมชันเบา ๆ ช่วยให้เข้าใจ: หน้าต่างเลื่อนขึ้น รายการใหม่กะพริบ หมุดใหม่ตกลงบนแผนที่ ตัวเลขนับขึ้น และรูปคนยืนในน้ำตามระดับที่เลือก (ปิดอัตโนมัติถ้าเครื่องตั้ง "ลดการเคลื่อนไหว")

- 🌦️ **สภาพอากาศ + เตือนอัตโนมัติ**: การ์ดสภาพอากาศตอนนี้ + กราฟฝนรายชั่วโมง 12 ชม. (ข้อมูล Open-Meteo, เซิร์ฟเวอร์ cache 10 นาที) และแถบเตือนอัตโนมัติเมื่อมีพายุฝนฟ้าคะนอง ฝนหนัก (≥10 มม./ชม. หรือสะสม 6 ชม. ≥20 มม.) ฝนต่อเนื่อง หรือลมกระโชก ≥40 กม./ชม. — ปุ่ม "แผนที่ลม/ฝน/เมฆ" เปิดแผนที่เคลื่อนไหวของ Windy.com (embed ฟรี โหลดเมื่อกดเท่านั้นเพราะใช้เน็ตมาก)

## กันการลงผิด (จากการวิเคราะห์การใช้งานจริงบน serithai57.com)
- **ขอความช่วยเหลือที่ลงผิดประเภท**: ถ้าข้อความใน “แจ้งข้อมูล/ฉันช่วยได้” มีคำอย่าง ผู้สูงอายุ ติดเตียง เด็ก ไม่มีไฟ ต้องการ ฯลฯ จะถามก่อนส่งว่าเป็นคำขอหรือไม่ และเปลี่ยนให้ในคลิกเดียว (เดาหมวด + ด่วน + จำนวนคนจากข้อความ) · ผู้ดูแลแก้ประเภทโพสต์ที่ลงผิดได้ในหน้ารายละเอียด
- **ปุ่ม “ด่วนมาก”** อยู่บนสุดของฟอร์ม และเปิดให้อัตโนมัติเมื่อเลือกหมวด ติดอยู่/อพยพ, เจ็บป่วย, ผู้สูงอายุ/ติดเตียง/เด็กเล็ก
- **หมุดไม่ได้เลื่อน**: เตือนก่อนส่งถ้ายังไม่ได้ลากแผนที่หรือกด GPS · ข่าวทั่วไปเลือก “ทั้งหมู่บ้าน / ไม่ระบุจุด” ได้ (ไม่ปักหมุด)
- **โพสต์ซ้ำ**: ถ้าบ้าน/จุดเดิมมีคำขอค้างอยู่ จะชวนไปอัปเดตโพสต์เดิม (“💬 ส่งข้อความอัปเดต” โดยไม่เปลี่ยนสถานะ) · แจ้งระดับน้ำจุดเดิมซ้ำใน 10 นาทีจะถามก่อน
- **ระดับน้ำ**: ใส่ความสูงเป็นเซนติเมตรได้ (เลือกระดับให้เอง เช่น 65 ซม. = ต้นขา) + แนวโน้ม ⬆️/➡️/⬇️ + วัดบนถนน/ในบ้าน · หมายเหตุที่ดูเหมือนขอความช่วยเหลือ จะเปิดฟอร์มขอความช่วยเหลือให้ต่อ
- **ถนน**: เพิ่มหมวด “⚠️ ผ่านได้บางส่วน / มีสิ่งกีดขวาง”
- **รายการ**: คำขอขึ้นก่อนเสมอ (ด่วน → ค้าง → ล่าสุด) · ป้าย “⏳ รอมา X ชม.” เมื่อไม่มีใครรับเรื่อง 3 ชม. · ข้อมูลเก่ากว่า 12 ชม. พับไว้
- **คนที่กด “ฉันจะไปช่วย”** จะถูกถามหลัง 2 ชม. ว่าเสร็จหรือยัง
- **ประกาศ**: ค่าเริ่มต้นหมดอายุ 24 ชม. · เกิน 6 ชม. ขึ้น “อาจไม่เป็นปัจจุบัน” และหยุดกะพริบ · ข้อความยาวพับเหลือ 3 บรรทัด
- **ปุ่ม 🆘 ลอย** มุมล่างขวาบนมือถือเมื่อปุ่มหลักเลื่อนพ้นจอ
- **ความเป็นส่วนตัว**: เบอร์โทรไม่อยู่ในรายการรวม ต้องกด “แสดงเบอร์โทร” ทีละโพสต์ (`GET /api/posts/{id}/contact`, จำกัดความถี่) และไม่อยู่ในสรุปที่ส่งเข้า LINE

## ผู้ดูแล (admin)
- **ลิงก์ลับ (เข้าเร็ว ไม่ต้องล็อกอิน):** `<เว็บ>/admin#key=<ADMIN_URL_KEY>` ค่าอยู่ใน `backend/.env` ใครมีลิงก์นี้ก็เป็นผู้ดูแลได้ ถ้าลิงก์หลุด ให้เปลี่ยน `ADMIN_URL_KEY` แล้วรีสตาร์ต backend
- **ล็อกอินด้วยอีเมล/รหัสผ่าน:** ที่ `/admin` บัญชีแรกสร้างจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` (ดู `memory/test_credentials.md`) ควรเปลี่ยนรหัสผ่านที่แท็บ "บัญชี"
- ผู้ดูแลทำได้: สร้าง / ปิด / ลบประกาศ, ปักหมุดหรือลบรายการใดก็ได้, ลบรายงานระดับน้ำ, เพิ่มหรือลบผู้ดูแลคนอื่น และดูประวัติการจัดการทั้งหมด
- ระดับน้ำมี 7 ระดับ: ไม่ท่วม · ตาตุ่ม · ครึ่งแข้ง · เข่า · **ต้นขา (60–70 ซม.)** · เอว · อกขึ้นไป (ข้อมูลเก่าถูกแปลงให้อัตโนมัติ)
- หน้าจอรีเฟรชข้อมูลเองทุก 20 วินาที และแสดง **"🟢 N คนกำลังดู"** (นับเครื่องที่เปิดหน้าอยู่ใน 60 วินาทีล่าสุด ไม่เก็บข้อมูลตัวตน)

## Stack (Emergent spec)
- `frontend/`: React (CRA) + Tailwind + Leaflet/OSM tiles, yarn, port 3000
- `backend/`: FastAPI + motor (MongoDB), port 8001, ทุก route อยู่ใต้ `/api`
- ไม่มีระบบล็อกอิน ผู้โพสต์ได้ edit key ที่เก็บไว้ในเบราว์เซอร์ของตัวเองสำหรับลบโพสต์ และจำกัดความถี่การโพสต์ต่อ IP

## สภาพอากาศบนโฮสต์ที่ใช้ IP ร่วมกัน (เช่น Emergent pod)
Open-Meteo ฟรีจำกัดจำนวนครั้ง**ต่อวันต่อ IP** บน pod ที่ออกเน็ตผ่าน IP เดียวกับแอปอื่น โควต้าอาจหมดโดยที่แอปเราแทบไม่ได้เรียก (ได้ `429 Daily API request limit exceeded`)
- backend จะข้าม Open-Meteo ไปจนถึง 00:05 UTC ของวันถัดไปแล้วใช้ **MET Norway** แทนอัตโนมัติ (ฟรี ไม่มีโควต้ารายวันต่อ IP)
- ค่าล่าสุดที่ดึงได้เก็บใน MongoDB (`weather_cache`) รีสตาร์ตแล้วยังมีข้อมูลแสดง (ข้อมูลเก่ากว่า 3 ชม. จะแสดงแต่ไม่ออกคำเตือน)
- ถ้าไม่มีแหล่งไหนตอบเลย หน้าเว็บจะขึ้น "ข้อมูลอากาศไม่พร้อมชั่วคราว" + ปุ่มแผนที่ Windy (โหลดจากมือถือโดยตรง) แทนการหายไป
- เลือก/เรียงแหล่งข้อมูลได้ด้วย `WEATHER_PROVIDERS` ใน `backend/.env` เช่น `WEATHER_PROVIDERS=met-norway` เพื่อไม่ใช้ Open-Meteo เลย
- ดูสถานะได้ที่ `GET /api/weather/status`
